# Promethia marketing site (v2 demo)

Single-page static site: plain HTML + CSS + a tiny JS file (Promo's tips). No build step, no tracking, no third-party requests (font self-hosted).

- `index.html` – home page (hero, audience paths, session quest, domains, proof of work, schools, pilot, FAQ)
- `credits.html`, `CREDITS.md` – image and font credits
- `assets/` – styles, script, font, images (WebP)

Deploy: GitHub Pages from the root of `main`.
